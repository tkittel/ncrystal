1. cpc2019_ncrystal_framework.pdf
==========================================================================
Citation: X.-X. Cai, T. Kittelmann, "NCrystal: A library for thermal neutron transport", Computer Physics Communications 246 (2020) 106851, doi:10.1016/j.cpc.2019.07.015 (received Jan 2019, online Aug 2019; describes NCrystal v1.0.0, Apache 2.0, program files doi:10.17632/s3rpb5d9j3.1).

Scope: Presents NCrystal as a C++ (C++98-compatible then) backend library with C/Python bindings and Geant4/McStas plugins, for thermal neutron scattering in crystalline materials describable as statistical arrangements of microscopic perfect crystallites within the Born approximation (powders/polycrystals, isotropic-Gaussian mosaic "single crystals", and layered crystals like pyrolytic graphite). The paper covers the theory overview, class design (RCBase/CalcBase/Process/Scatter/Absorption/Info), the .ncmat/.nxs/.laz/.lau loaders, the hkl-list initialisation algorithm, the data library (43 materials, Table 3), validation, the cfg-string configuration syntax, and the interfaces. Detailed physics of the Bragg models and the inelastic model was explicitly deferred to "future dedicated publications". Not supported at the time: surface effects, non-crystalline or textured materials, Born-approximation breakdown (guides, perfect Si), magnetic scattering, nuclear resonances.

Physics models / formulas:
- Crystal basics: p_i = x_i a + y_i b + z_i c; reciprocal basis tau_a = 2pi (b x c)/V_uc etc.; tau_hkl = h tau_a + k tau_b + l tau_c; d_hkl = 2pi/|tau_hkl|.
- Master equation (Eq. 6/8): d2sigma/dOmega dE_f = (k_f/k_i) S(Q,omega), Q = k_f - k_i, Fermi pseudopotential V(r) = (2pi hbar^2/m) sum_j b_j delta(r - R_j). Scattering lengths treated as real constants; absorption handled separately (valid at O(1e-4)).
- Coherent/incoherent split (Eqs. 13-16) via ensemble average <b_j b_j'> = <b_j><b_j'> (j != j') or <b_j^2> (j = j'), giving S = S_coh + S_inc with b_coh and b_inc; sigma_coh + sigma_inc ~ sigma_free for thermal neutrons.
- Harmonic approximation (Eq. 19): <j,j'> = exp(-iQ.(d_j' - d_j)) exp(-W_j') exp(-W_j) exp(<(Q.u_j'(0))(Q.u_j(t))>), Debye-Waller function W_j(Q) = (1/2)<(Q.u_j(0))^2>, and phonon expansion (Eq. 21): exp(<...>) = sum_n (1/n!) <(Q.u_j'(0))(Q.u_j(t))>^n, nth term = n-phonon interaction.
- Incoherent elastic (Eq. 23): d2sigma/dOmega dE = sum_j (<b_j^2> - <b_j>^2) exp(-2W_j(Q)) delta(hbar omega), isotropic at long wavelength, forward-peaked at high E/T since Q = 2 k_i sin(theta/2).
- Coherent elastic per unit cell (Eq. 31): S_coh^el(Q,omega) = (2pi)^3/V_uc delta(hbar omega) sum_hkl delta(Q - tau_hkl) |F(tau_hkl)|^2, with unit-cell form factor (Eq. 25) F(Q) = sum_i b_i exp(-W_i(Q)) exp(iQ.p_i). Bragg condition lambda <= 2 d_hkl, Bragg equation lambda = 2 d_hkl sin(theta/2).
- Powder Bragg cross section (Eq. 35, isotropic average of the delta functions, Eq. 34 gives lambda^2 d/(16 pi^3) per plane): sigma_el,coh^powder(lambda) = (lambda^2 / (2 V_uc)) sum_{hkl: lambda<=2d_hkl} d_hkl |F(tau_hkl)|^2. Plane chosen with probability proportional to its term; theta from Bragg equation; azimuth uniform (Debye-Scherrer cone). Implemented as PCBragg.
- Single crystal: SCBragg = isotropic Gaussian mosaicity (FWHM parameter `mos`), orientation via dir1/dir2 (`@crys:`/`@crys_hkl:` ... `@lab:`), dirtol; LCBragg = anisotropic layered-crystal model (crystallites aligned around one axis `lcaxis`, random rotation about it, used for pyrolytic graphite via embedded NCRYSTALMATCFG[lcaxis=0,0,1]). NO equations or sampling algorithm for the mosaic model are given in this paper (deferred to a later publication).
- Debye model for MSD (Eqs. 36-40, after Glauber 1955): <u_alpha^2> = integral_0^{hbar omega_D} (hbar/(2 M omega)) coth(hbar omega/(2 k_B T)) rho(hbar omega) d(hbar omega) with rho = 3 omega^2/(hbar omega_D^3), giving <u_alpha^2> = (3 hbar^2/(M k_B T_D)) f(T/T_D), f(x) = x^2 integral_0^{1/x} coth(u/2) (u/2) du = 1/4 + x^2 integral_0^{1/x} u/(e^u - 1) du (identical to Glauber Eq. 11; nonzero at 0 K). Then W_j(Q) ~ (1/2) Q^2 delta_j^2 with delta_j^2 the isotropic MSD; exp(-W_i(tau_hkl)) = exp(-2 pi^2 delta_i^2 / d_hkl^2). Debye temperature global or per element (Table 2 / @DEBYETEMPERATURE).
- Inelastic at the time (Sec. 2.4, 3.1): powder S(Q,omega) 2-D; options discussed (kernels, MD, empirical Freund/Cassels formulas, which are called inaccurate at intermediate lambda). NCrystal 1.0 used BkgdPhonDebye: Sjolander's (Ark. Fys. 14 (1958) 315) iterative procedure estimating the n-phonon term from the (n-1)-phonon term, starting from the single-phonon term under the Debye model, plus Placzek's incoherent approximation (coherent inelastic treated like incoherent), giving only a cross-section curve. Sampling was via ScatterXSCurve: isotropic scattering angle, and energy either unchanged ("elastic", `bkgd=phonondebye:elastic`) or "fully thermalising" (Maxwell at material T). BkgdExtCurve wraps the nxslib empirical curves (reference only). The rejection-sampling prototype [53] (paper 2 below) is cited as future enhancement with kernels/phonon DOS.
- Absorption: AbsOOV, 1/v scaling of sigma_abs(2200 m/s). MC step length -L log(R) (footnote 4). Default RNG xoroshiro128+.
- hkl list initialisation: all hkl with d_hkl >= d_cut; |F|^2 computed directly from Eq. 25, using |F(tau)|^2 = |F(-tau)|^2 symmetry, discarding |F|^2 < f_cut = 1e-5 b, with an early-abort upper bound (sines/cosines replaced by 1) so init time tends to a constant as d_cut -> 0 instead of O(1/d_cut^3); families grouped by (d, |F|^2) via map, O(log). Default d_cut = 0.1 Aa (0.25 Aa for >40 atoms/cell, keeping load times <~1 s; Y2O3 took 31 s at 0.1 Aa). .nxs: d_cut mapped to Nmax, default such that Nmax = 20 clamped to [0.1, 0.5] Aa, error if Nmax > 50.

Claims / validation:
- .ncmat atomic positions and hkl lists cross-checked vs nxslib/SgInfo (Wyckoff + space-group generated) for all files ("N"); McStas-simulated powder patterns refined with GSAS-II (4 materials, R < 1.9%, e.g. corundum R = 0.82%, recovers lattice params, positions, MSDs); idealised patterns (Gaussian 0.1 deg lines, 1/sin theta acceptance) refined with FullProf for 17 materials (R < 2.7%); measured |F|^2 for monoclinic SiLu2O5 reproduced; EXFOR total cross sections (Mo, Ni, Zn, UO2, Sn shown) agree in Bragg edges and single-phonon region; Ni agreement supports ignoring magnetic scattering for unpolarised beams; Sn shows a 1.3 eV resonance not modelled. Geant4 plugin: absorption identical to Geant4 (1/v), scattering replaced below a hard-coded 5 eV crossover; Fig. 19 free-gas diffuse vs Debye-Scherrer cones.
Limitations / future work (Sec. 7): detailed inelastic sampling, kernels/phonon DOS input, liquids/polymers; multi-phase materials, enrichment/chemical disorder/partial occupancy; multithreading; in-memory data; drop C++98; texture, bent crystals, new anisotropic mosaicity models, resonances, magnetic scattering, X-rays.

2. jcomp_2018_rejection-based_sampling_of_inelastic_neutron_scattering_xxcai.pdf
==========================================================================
Citation: X.-X. Cai, T. Kittelmann, E. Klinkby, J.I. Marquez Damian, "Rejection-based sampling of inelastic neutron scattering", Journal of Computational Physics 380 (2019) 400-407, doi:10.1016/j.jcp.2018.11.043 (online 13 Dec 2018).

Scope: An accurate and efficient rejection method for sampling final states directly from a tabulated isotropic scattering kernel S(alpha,beta) at an arbitrary incident energy, avoiding the usual interpolation between pre-sampled distributions at bracketing grid energies. It is NOT about a phonon expansion from a VDOS: the kernel is assumed given (e.g. from NJOY/LEAPR, ENDF TSL). Benchmarked against the analytic free-gas kernel and MCNP6/OpenMC water-sphere spectra; concludes the implementation "will be integrated into NCrystal".

Method / formulas:
- d2sigma/dE' dOmega = sqrt(E'/E) (sigma_b/(4 pi)) S(alpha,beta)/(k_B T) (Eq. 1), alpha = (E + E' - 2 mu sqrt(E E'))/(k_B T), beta = (E' - E)/(k_B T) (Eq. 2). NOTE: alpha here deliberately omits NJOY's factor M/m (A), because a target mass is ambiguous for coherent kernels of multi-isotope materials.
- Kinematic limits: beta >= -E/(k_B T); alpha_+-(beta) = (2E + k_B T beta +- 2 sqrt(E (E + k_B T beta)))/(k_B T) (Eq. 3). Region D(E) = {beta >= -E/kT, alpha_- <= alpha <= alpha_+} grows monotonically with E.
- sigma(E) = (C/E) integral integral S(alpha,beta) Theta(alpha,beta) dalpha dbeta, C = sigma_b k_B T/4 (Eq. 4); PDF p(alpha,beta|E) = C S Theta/(sigma(E) E) (Eq. 7).
- Key trick (Eqs. 9-11): for E_l < E_h, p(alpha,beta|E_l) = [sigma(E_h) E_h/(sigma(E_l) E_l)] p(alpha,beta|E_h) Theta_l(alpha,beta). So sample (alpha,beta) from the precomputed distribution at the next-higher grid energy E_h and accept iff it lies in D(E_l) (no extra uniform needed since the acceptance function is 0/1). Acceptance rate M = sigma(E_l) E_l/(sigma(E_h) E_h) (= sqrt(E_l/E_h) in the 1/v region), typically >90% on a dense grid.
- Algorithm 1 (fast): find smallest E_i >= E; repeat {sample beta' from P(beta|E_i) until beta' > -E/kT; find bracketing beta_j; sample alpha from F(alpha|beta_{j-1},E_i) and F(alpha|beta_j,E_i), interpolate linearly} while alpha' not in [alpha_-, alpha_+]. Algorithm 2 = same without the early beta rejection (predictable speed). Algorithm 3 = same idea applied to tabulated ACE double-differential (E', mu) data.
- Numerics (Sec. 2.1): F(alpha|beta) = integral_0^alpha S dalpha, piecewise with ENDF log-linear interpolation of S in alpha: integral_{a1}^{a2} S = (a2-a1)(S2-S1)/log(S2/S1) (Eq. 14; trapezoid fallback), inverted analytically for sampling (Eq. 17, with cached y = log(S_{k+1}/S_k)); conditional CDF F(alpha|beta,E) = (F(alpha|beta) - F(alpha_-|beta))/(F(alpha_+|beta) - F(alpha_-|beta)) (Eq. 15); beta integral by trapezoid (Eq. 18), with beta grid refined where needed (quasi-elastic peak), convergence judged on total cross section.
- Free-gas reference kernel (Eq. 19): S(alpha,beta) = exp(-beta/2)/sqrt(4 pi alpha/A) exp(-(alpha^2/A^2 + beta^2)/(4 alpha/A)), A = M/m. For A = 1, sigma_free = 1: sigma(E) = (1 + 1/(2a^2)) erf(a) + exp(-a^2)/(a sqrt(pi)), a = sqrt(E/kT) (Eq. 20); energy-transfer PDF f(E->E') = exp(beta) erf(sqrt(E/kT))/(E sigma(E)) for E < E', erf(sqrt(E'/kT))/(E sigma(E)) for E > E' (Eq. 21).

Claims / validation: total xs error < 0.05% below 0.1 eV, 0.2% at 1 eV vs analytic; sampled E' distributions at 0.01 eV from bounding distributions at 0.011 and 0.1 eV statistically identical to Eq. 21; speed ~ 1/M; 30 cm free-gas water sphere flux within a fraction of a percent of MCNP6 classical between 1e-3 and 1 eV, exposing a ~5% MCNP6 continuous-model overestimate near the source energy (absent in OpenMC) and unphysical low-energy fluctuations (up to 65%) in MCNP6 with the CAB bound-H kernel; ACE discrete-data runs: 96.9% acceptance, only ~1% faster overall.
Limitations: assumes an isotropic kernel and tabulated (alpha,beta) grid; trapezoid beta integration is the main error source for sharp features; off-resonance only.
What NCrystal implements: the (alpha,beta) convention without M/m, the kinematic limits alpha_+-(beta), and rejection-based sampling in the sab/sabscatter code (e.g. NCSABSampler.cc, NCSABSamplerModels.cc "Rejection method failed to sample kinematically valid (alpha,beta) point"). The free-gas S(alpha,beta) of Eq. 19 and the sigma(E) of Eq. 20 are what `ncrystal_core/include/NCrystal/internal/phys_utils/NCFreeGasUtils.hh` cites ("equation 19 in the NCrystal sampling paper (10.1016/j.jcp.2018.11.043)").

3. preview_paper_checksec2d4forfreegassampling_gmd-2022-93.pdf (URANOS, Sec. 2.4)
==========================================================================
Citation: M. Kohli, M. Schron, S. Zacharias, U. Schmidt, "URANOS v1.0 - the Ultra Rapid Adaptable Neutron-Only Simulation for Environmental Research", GMD Discussions preprint, doi:10.5194/gmd-2022-93 (2022). A cosmic-ray-neutron-sensing MC code; not an NCrystal paper (it mentions NXSG4, Kittelmann & Boin 2015, only as a Geant4 extension).

Section 2.4 "Sampling thermal velocity distributions": the classical free-gas target-velocity sampling preserving the thermally averaged reaction rate (Gelbard 1979; implementation after OpenMC, Romano & Forget 2013, and Walsh et al. 2014):
- v sigma(v,T) = integral v_r sigma(v_r) f_M(V) dV (Eq. 6); reaction-rate integrand R(V) = |v - V| sigma(|v - V|) f_M(V) (Eq. 7); v_r = sqrt(v^2 + V^2 - 2 v V mu).
- With beta = sqrt(m/(2 k_B T)), mu = cos(theta): p(V,mu) dV dmu = (4 sigma(v_r)/(sqrt(pi) C')) sqrt(v^2 + V^2 - 2 v V mu) beta^3 V^2 exp(-beta^2 V^2) dV dmu (Eq. 10).
- Factorise p = g1 g2 with g1 = (4 sigma(v_r)/(sqrt(pi) C')) sqrt(v^2+V^2-2vV mu)/(v+V) (bounded) and g2 = (v+V) beta^3 V^2 exp(-beta^2 V^2); integral g2 = (sqrt(pi) beta v + 2)/(4 beta) (Eq. 14). With x = beta V, y = beta v: q(x) dx = [ (sqrt(pi) y/(sqrt(pi) y + 2)) (4/sqrt(pi)) x^2 exp(-x^2) + (2/(sqrt(pi) y + 2)) 2 x^3 exp(-x^2) ] dx (Eq. 16).
- Scheme: xi1 < 2/(sqrt(pi) y + 2) -> sample x from 2 x^3 exp(-x^2), else from (4/sqrt(pi)) x^2 exp(-x^2) (Eq. 17); V = x/beta; mu = 2 xi2 - 1 (Eq. 18); accept iff xi3 < sqrt(v^2 + V^2 - 2 v V mu)/(v + V) (Eq. 19) (assuming constant sigma(v_r), i.e. no resonance correction); otherwise resample. Then elastic scattering in the CM frame.
Relation to NCrystal: NCrystal does NOT use this classical target-velocity scheme. Its free-gas model (`ncrystal_core/src/freegas/NCFreeGas.cc`, `FreeGasSampler` in `NCFreeGasUtils.hh`) samples (beta, alpha) directly from the analytic free-gas S(alpha,beta) (paper 2, Eq. 19) with specialised beta and alpha sampling valid up to ~1 GeV at ~1 MHz; the two are statistically equivalent for a classical ideal gas (paper 2, Sec. 3.2). The URANOS scheme is useful only as a cross-check reference.

4. multinomial.pdf
==========================================================================
Citation: C.S. Davis, "The computer generation of multinomial random variates", Computational Statistics & Data Analysis 16 (1993) 205-217 (North-Holland).
Scope: Statistics paper comparing seven algorithms for generating multinomial M_k(N,p) vectors: direct ("ball-in-urn") and sorted-direct; alias method (Walker) applied N times; conditional-binomial decomposition X_i ~ B(N - sum_{j<i} X_j, p_i/(1 - sum_{j<i} p_j)) with Bernoulli, inverse-CDF or Kemp's modal binomial generator; Brown-Bromberg two-stage (k Poisson variates with sum conditioned to N, topped up with alias draws). Empirical study: N = 50..500, k = 3..100, 1000 vectors each, FORTRAN on a PS/2.
Claims: Brown-Bromberg fastest but complex set-up and 2k(N+2) storage (and single-precision Poisson-probability accuracy issues for N = 500, k >= 36); conditional-inverse limited by underflow (n < log(c)/log(max(p,1-p))); conditional-modal (Kemp 1986, with two errata corrected) recommended as the all-purpose method: no set-up, no storage, exact, within ~1 min/1000 variates of the fastest. Limitations: dated hardware, single precision, no physics.
Relation to NCrystal: none in the physics (it is not about multi-phonon expansion or cross-section sampling). The only connection found in the repo: `tests/pypath/NCTestUtils/sabcelleval.py` (line ~535) needs multinomial counts per region for a reference S(alpha,beta) sampler and works around mpmath lacking one by sorting N uniforms against cumulative thresholds (the "direct" method of Davis Sec. 2.1). The paper would be relevant if one ever wanted a faster exact multinomial for distributing sample counts over kernel cells/regions in test or sampling code.

5. seeger2002_nisp_mosaic_crystal_algorithm_for_MC_sims.pdf
==========================================================================
Citation: P.A. Seeger, L.L. Daemen, "Mosaic crystal algorithm for Monte Carlo simulations", Applied Physics A 74 (Suppl.) (2002), doi:10.1007/s003390201792 (ResearchGate author copy, NISP package).
Scope: A step-wise transport algorithm for mosaic monochromator/analyser crystals in NISP: fixed step length t treated as the mosaic block size (uncorrelated plane orientation per step), exact Darwin-equation solution per step (Sears 1997), kinematical Bragg cross section with Gaussian mosaic function integrated by MC, Debye-Waller via a new exponential-series expansion of the Debye integral, and a crude "absorption" term (incoherent + 1/v nuclear + Einstein-like coherent inelastic). Secondary extinction and beam "walking" emerge from the stepping; primary extinction is not modelled; any crystal shape/plane orientation allowed.

Algorithm / formulas (Greek symbols were lost in text extraction; reconstructed):
- Dimensionless parameters: a = mu t (macroscopic non-Bragg xs), b = sigma t (macroscopic Bragg xs), gamma = sin(theta)/sin(theta') set to 1 (planes parallel = Bragg case or perpendicular = Laue case to the surface).
- Thin-step limit: A = a, R = b, T = 1 - R - A (same for Bragg and Laue to first order). When T would be too small, full Sears solutions: Bragg geometry p = a + b, r = sqrt(a^2 + 2ab), R = b sinh(r)/(r cosh(r) + p sinh(r)), T = r/(r cosh(r) + p sinh(r)); Laue geometry R = exp(-p) sinh(b), T = exp(-p) cosh(b); A = 1 - R - T. If t spans the crystal, interaction assumed at mid-depth, no secondary extinction.
- Kinematical Bragg xs: sigma(lambda,theta) = Q(lambda) W(theta - theta_B), Q = lambda^3 |F_hkl|^2/(V0^2 sin(2 theta_B)) = lambda^2 d_hkl |F_hkl|^2/(n V0^2 cos(theta_B)). Tabulated S = t d_hkl (|F_hkl| e^{W}/V0)^2 (DW factor pulled out so T can vary), giving per-step reflectivity b = sigma t = lambda^2 S exp(-2W_hkl)/(n cos(theta_B)), n chosen to minimise |theta - theta_B|; Gaussian W(theta - theta_B) handled by MC integration. Singularity at lambda = 2d (theta_B = 90 deg) capped by a lower limit on cos(theta_B) at 1 deg off normal (kinematical model invalid in backscattering). S may be fitted to measured reflectivities rather than crystallography.
- Debye-Waller: u0^2 = (3 h^2/(4 pi^2 M k theta_D)) [phi(x)/x + 1/4], x = theta_D/T, phi(x) = (1/x) integral_0^x t/(e^t - 1) dt; 2W_hkl = (4 pi u0 sin(theta_B)/lambda)^2 = (2 pi u0/d_hkl)^2. New series: 1/(1 - e^{-t}) = sum_j e^{-jt}, integrate by parts: integral_0^x t/(e^t - 1) dt = pi^2/6 - sum_{j>=1} e^{-jx} (x/j + 1/j^2) (using zeta(2) = pi^2/6); two terms give < 0.2% for x > 2, truncation at term < 0.01 with geometric-series tail, worst case Pb at RT (x = 0.36) seven terms, 0.4%.
- Non-Bragg attenuation per step: a = t [Sigma_i + Sigma_a0 lambda + Sigma_c f(x)], f(x) = 1 - (1 - e^{-x})/x, x = (4 pi u0/lambda)^2 (Einstein-like coherent inelastic model); theta_D values are reduced below thermodynamic values to reproduce measured u0 at 295 K (e.g. Si 500 K instead of 640 K to get u0 = 0.081 Aa).
Claims / validation: Si(111) 1 cm, 2 mm steps reproduces Sears' analytic peak reflectivity vs wavelength in Bragg and Laue geometry (Gaussian rms 2.09e-3 rad, FWHM 0.282 deg, W(0) = 191/rad); PG(002) 0.22 cm rocking-curve peak and width vs energy fitted to Shapiro & Chesser data at 14 meV; PG total xs vs angle at 1.116 Aa agrees with Grabcev. Limitations: no primary extinction; kinematical model fails in backscattering; blocks at inclined surfaces inaccurate unless t small; mosaic block size tied to step length; empirical parameter tuning (theta_D, S).
Relation to NCrystal: NCrystal's SCBragg (`ncrystal_core/src/scbragg/NCSCBragg.cc`) likewise assumes a Gaussian distribution of crystallite orientations with FWHM `mos` and truncation (`ntrunc`), but computes an actual per-crystallite cross section integrated over the mosaic distribution and relies on the host MC stepping for extinction-like effects (CPC paper Sec. 2.2), rather than Seeger's Darwin per-step R/T/A bookkeeping. The CPC paper cites NISP only as a specialised instrument code [17].

6. mcstas_PowderN_Willendrup2006.pdf
==========================================================================
Citation: P. Willendrup, U. Filges, L. Keller, E. Farhi, K. Lefmann, "Validation of a realistic powder sample using data from DMC at PSI", Physica B 385-386 (2006) 1032-1034, doi:10.1016/j.physb.2006.05.329.
Scope: A 3-page virtual-experiment paper: McStas 1.9 model of the DMC cold powder diffractometer at PSI (PG(002) monochromator, 2.567 Aa, 400-channel PSD) with the then-new PowderN component, compared with real DMC data on Na2Ca3Al2F14.
PowderN model (as described here; details in the McStas component manual): powder lines (position, amplitude, optional broadening, DW factors) read from an external file (here LAZY output, i.e. .laz, with DW = 1 and no intrinsic broadening); inputs per unit cell V_c = 1076.98 Aa^3, sigma_abs = 11.784 b, sigma_inc = 13.672 b, packing factor 0.7. Each ray either scatters on one powder line or incoherently (MC choice with user-controllable, intensity-preserving bias); optional focusing of scattered rays toward the scattering plane; absorption by weight reduction. No container, no multiple scattering, no thermal diffuse scattering. No formulas given in the paper.
Claims / validation: peak positions within 0.05 deg, line shapes and 2theta-dependent broadening reproduced, background (vanadium can, simulated separately with V_sample) correct; but absolute line intensities required an ad hoc scaling factor of 10, guide flux simulated 4.9e8 vs measured 2.46e8 n/s/cm^2/mA; CaF2 impurity (220) peak and theta-dependent background (attributed to TDS) not reproduced. Limitations stated: no multiple scattering, no TDS, no sample environment, 0.03% of rays hit sample (plan: let each ray contribute to every line once, as in VITESS).
Relevance as baseline: NCrystal's PCBragg uses the same kind of hkl/d/|F|^2 input (it can read .laz/.lau files, CPC paper Sec. 4.3) but computes |F|^2 with temperature-dependent DW factors from .ncmat, includes multiple scattering via proper cross sections, and adds inelastic/incoherent components; the CPC paper validates NCrystal's own powder patterns with GSAS-II/FullProf rather than against PowderN.
