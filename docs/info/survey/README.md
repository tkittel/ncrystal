# Raw survey notes

Unedited inventories produced on 2026-10-20 by AI agents surveying the
NCrystal code (branch `tk_volatile`), the papers in `nocheck/papers`, the
GitHub wiki, the notebooks repository and the publication record. They are
the raw source notes behind the chapters in `docs/info/`, kept for reference
while those are written. They are not reviewed, may contain mistakes, and
are meant to be removed from the history before anything is merged into
`develop` (they are in a single commit of their own for that reason).
